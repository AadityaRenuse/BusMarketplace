# Bus & Minibus Rental Marketplace

A digital marketplace for renting buses and minibuses for group travel.

## Problem Statement 

To design and develop a centralized digital bus and minibus rental marketplace that enables customers to post travel requirements, browse available busses, receive competitive bids from verified travel operators (reverse bidding), compare available rides, and book the most suitable service through a transparent, secure and efficient platform.

## Core Features

- Instant bus/minibus booking
- Reverse bidding between customers and travel operators
- Bus and agency listings
- Operator verification
- Booking management
- Reviews and ratings
